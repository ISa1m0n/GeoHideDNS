# Домены для оценки покрытия прокси (tools/geohide-probe.ps1).
#
# Зачем: адрес из чужого DoH-списка часто проксирует только часть сервисов.
# Если поставить такой адрес в MAIN, hosts-ai.txt соберётся, DnsConf его применит,
# а половина сайтов молча перестанет открываться. Поэтому перед выбором MAIN скрипт
# проверяет, какие домены адрес реально отдаёт, и берёт лучший по покрытию.
#
# Правила:
#   - только домены, которые есть в hosts-ai.txt;
#   - не добавлять google-домены: они идут через GEMINI (custom-hosts.txt);
#   - отвечает любой HTTP-код (200, 301, 403) - значит TLS прошёл и прокси домен знает.
#   - ошибка 35 и таймаут означают, что домен через этот адрес не ходит.
#
# Домены ниже - то, чем реально пользуется владелец форка. Порядок не важен.
